YOUR CHARTS, ON YOUR COMPUTER

A home for your chart library.

Create one empty file. Teeth Chart will fill it with all your charts and keep it updated as you work.

Name your fileOnline Teeth Chart App.json

    Set up local saving

    1. Open a new TextEdit document

      Open TextEdit from Applications, then choose File → New.

    2. Make it plain text

      Choose Format → Make Plain Text (⇧ ⌘ T). Leave the document completely empty.

    3. Save with the exact name

      Choose File → Save and name it Online Teeth Chart App.json. Choose a folder you can find again. Uncheck “If no extension is provided, use .txt.” If asked about the extension, choose Use .json. The name must end in .json, not .json.txt.

    4. Connect it to your charts

      Return to your chart tab, click Choose JSON file, select this file, and allow the site to read and save changes.

    Apple’s TextEdit guide ↗

    1. Open a plain-text editor

      Open your desktop’s text editor, such as Text Editor or Kate, and create a new document.

    2. Leave it empty

      Do not type any text. Use a plain-text document, rather than a word-processing document.

    3. Save your JSON file

      Choose Save As, name the file Online Teeth Chart App.json, and save it in Documents or another folder you can find again. Keep the .json extension.

    4. Connect it to your charts

      Return to your chart tab, click Choose JSON file, select this file, and allow the site to read and save changes.

    1. Open a blank Notepad document

      Open Start, search for Notepad, and create a new document. Leave it empty.

    2. Choose Save As

      Open File → Save As. Choose Documents or another folder you can find again.

    3. Set the name and file type

      Enter Online Teeth Chart App.json as the file name. Set Save as type to All files, keep UTF-8 encoding, and click Save. The name must end in .json, not .json.txt.

    4. Connect it to your charts

      Return to your chart tab, click Choose JSON file, select this file, and allow the site to read and save changes.

    Microsoft’s Notepad help ↗

    1. Create the empty file

      Click Download blank JSON file below. This creates an empty file with the correct name; no text editor is needed.

    2. Find it in Files

      Open the Launcher, then Files → Downloads, or the folder you chose when downloading.

    3. Keep the correct name

      Check that it is called Online Teeth Chart App.json. If the browser added a number because a file already exists, rename the new blank file only if it will not replace your existing library.

    4. Connect it to your charts

      Return to your chart tab, click Choose JSON file, select this file, and allow the site to read and save changes.
